# Facebook RSVPs

If you RSVP on Facebook, you now show up on the website too.

- **Going on one of our Facebook {{events}}?** You'll appear in "Who's coming"
  here as well — Facebook RSVPs sync to the site automatically, so the
  headcount includes everyone.
- **Your +1s from the Facebook comments count too**, and show beside your name.
- **You'll get the usual confirmation email** if Facebook puts you on the list,
  noting that it came from Facebook. If that's not right, change your RSVP on
  the {{events}} page.
- **Organizers can add you to Going** from the attendance list if you tell them
  you're coming.
